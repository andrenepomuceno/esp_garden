Rename a device or move it to another GPIO. How many devices exist is decided when the firmware is built — RELAY_COUNT and MOISTURE_SENSOR_COUNT in platformio.ini — so there is nothing here to add or delete: an extra entry in config.json is ignored by the device and a missing one keeps its compiled default. Edits are written to config.json and only take effect after a restart.
Actuators
Index Name GPIO Active Now Test
Index is how a relay is addressed — the name is only a label. Test switches the relay on for three seconds using the pin the device is running on, not the one typed above. Active is the idle-vs-energised level; it is edited in Config, because inverting it turns a pump on.
Sensors
Device Name GPIO Reading
A sensor name is the dashboard label: /data.json keys its Inputs by it. A name on the DHT is a prefix, because one pin produces both temperature and humidity. Names are labels, not identifiers — telemetry keys and the history record stay positional, so a rename never rewrites stored data.
