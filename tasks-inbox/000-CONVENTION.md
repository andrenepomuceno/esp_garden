# Task folders

`tasks-inbox/` is work intended. `tasks-done/` is work finished — move the file,
do not delete it, so the reasoning survives with the commit that closed it.

**These folders do NOT duplicate CLAUDE.md's "What has actually run".** That list
is claims waiting for evidence; this one is work waiting for a person. A task
that lands usually ADDS an entry to the Unverified list rather than clearing one.
Two lists saying the same thing is how this repo has already been wrong three
times.

One file per task, `NNN-slug.md`, with: why it matters, what "done" means, and
what blocks it. Keep them short. A task nobody would act on is a note, and notes
belong in CLAUDE.md.
